## 2. 验收范围

### 2.1 用户可见页面

| 页面/入口 | 验收重点 |
| --- | --- |
| 首页 `/` | 园所展示、导航、图片资源、页面跳转、移动端布局、悬浮智能体入口。 |
| 科小贝实验室 `/lab` | 科学诗、科学故事、科学实验的浏览、筛选、检索、详情、视频、资源附件、智能体辅助和新增材料。 |
| 作品展示 `/works` | 免登录浏览与共创提交、作品详情、互动和成长内容展示。 |
| 悬浮智能体 | 文字对话、附件、拍照提问、语音输入/播报、教案与材料分析、智能体结果卡片。 |

当前产品不设置注册、登录或用户角色区分。验收以同一个公开使用状态为准，不将账号页或角色权限作为用户功能验收。代码中的 `SchoolPortal` 不是现行首页渲染内容，本轮不作为公开网站页面验收。

### 2.2 服务与数据链路

| 链路 | 验收重点 |
| --- | --- |
| Dify/模型服务 | 文本、文件和图片输入能被正确转发；超时、无结果、服务不可用时有明确提示，不泄露密钥或内部报错。 |
| Vercel Blob | 材料、视频、封面和作品上传后地址可公开访问；刷新页面后资源仍存在。 |
| PostgreSQL/Prisma | 科学资料、作品、评论、成长记录等内容的写入、读取、刷新后持久化与既有数据保护正确。 |
| 语音能力 | 浏览器语音识别和 TTS 可用时正常工作；不支持或拒绝授权时降级提示清晰。 |
| 线上部署 | 正式域名、HTTPS、缓存更新、构建日志、关键 API 健康状态正常。 |

### 2.3 不在本轮“上线验收”中直接执行的高风险操作

- 不在正式库批量删除、覆盖或重新导入现有资料。
- 不使用真实儿童个人信息、未授权照片或敏感教案作为测试文件。
- 不在未经单独确认的情况下修改生产环境变量、数据库结构或 Dify 工作流。
- 真实机器人硬件联调仅验证 API 协议与模拟回执；实体设备动作、安全场地和教学现场另行验收。

### 2.4 本次验收原则

- 只验证当前已经存在的页面与功能是否正常运行，不把未提出的新能力列为验收整改项。
- 发现问题时优先修复功能错误、数据异常、手机端错位、缩放异常、点击无响应和加载卡顿，不进行与验收无关的页面重设计。
- 所有移动端结论以真实手机或等效视口实际操作为准，不能只根据桌面浏览器代码判断。

## 3. 验收通过门槛

1. P0、P1 问题为 0：不得存在页面无法访问、数据丢失、既有内容被任意覆盖、主要功能不可用或展示现场会中断的故障。
2. 核心用例通过率为 100%：资源库浏览、材料新增、封面处理、智能体对话、作品上传与跨设备浏览必须全部通过。
3. 一般用例通过率不低于 95%：其余兼容性、视觉和易用性用例须记录结果；未通过项必须有明确的修复计划或书面豁免。
4. 桌面端和移动端均不存在遮挡、文字溢出、不可点击、无返回路径或无加载反馈的问题。
5. 线上关键页面和 API 在验收期间可稳定访问，且不出现浏览器控制台未处理异常。

### 问题分级

| 级别 | 定义 | 示例 | 处理要求 |
| --- | --- | --- |
| P0 阻断 | 网站或关键流程完全不可用，或出现数据/安全事故。 | 首页或资源库无法打开、上传后数据丢失、访客可任意覆盖既有资料。 | 立即停止验收，修复后全量回归。 |
| P1 严重 | 主展示流程无法完成，但有局部页面可用。 | 智能体不能回复、科学诗无法保存、视频无法播放。 | 上线/展示前必须修复。 |
| P2 一般 | 功能可继续使用但结果、交互或部分场景不正确。 | 生成封面不自动替换、筛选计数错误、手机端按钮位置不合理。 | 本轮尽量修复；无法修复时需记录风险。 |
| P3 优化 | 不影响任务完成的文案、间距、动效或视觉优化。 | 图标提示不够明确、卡片留白不一致。 | 归入体验优化清单。 |

### 4.2 移动端适配与交互测试矩阵

| 场景 | 覆盖页面 | 验收重点 |
| --- | --- | --- |
| 首屏与导航 | 首页、实验室、作品页 | 首屏不横向溢出；标题、主图、导航和底部导航完整可见；切换页面时无明显跳动。 |
| 资源列表与详情 | 实验室 | 筛选、搜索、卡片、详情弹窗、视频和图片会随宽度重排；不裁切文字，不遮挡卡片操作。 |
| 悬浮智能体 | 首页、实验室、作品页 | 智能体不被底部导航遮挡；展开后的对话框、输入框、附件预览和菜单不超出屏幕。 |
| 输入与键盘 | 智能体、材料新增、作品提交 | 聚焦输入框后浏览器不突兀自动放大；软键盘出现时发送按钮、输入内容和关闭按钮仍可操作。 |
| 触控与响应 | 所有可点击入口 | 轻触后 150ms 内有按压/打开等可见反馈；网络操作 500ms 内出现加载状态；重复点击不重复提交。 |
| 缩放与旋转 | 所有页面 | 在浏览器缩放、系统字体变大、横竖屏切换后，页面不出现横向滚动、重叠、空白或不可点区域。 |

全部场景均使用新的无痕浏览器状态和同一个公开访问方式执行；不创建测试账号、不登录、不注册。测试材料标题统一使用“验收-日期-功能”前缀，方便筛选；生产测试数据的归档或删除须在验收完成后单独确认。

### 4.3 测试材料集

1. 科学诗：一份纯文本、一份 DOCX/PDF、一份图片化诗稿；分别覆盖“上传自定义封面”和“不上传封面”。
2. 科学故事：一段可正常播放的 MP4、一个较大文件、一个不支持格式；分别覆盖“自定义封面”和“视频首帧封面”。
3. 智能体输入：普通提问、实验图片、教案/研修文档、超长文本、空内容、异常文件类型。
4. 学生作品：图片、视频、文本说明；覆盖免登录提交、公开浏览、刷新后显示、媒体预览和互动反馈。
5. 安全样本：含 HTML 标签、脚本片段、超长文件名和不规范扩展名的非敏感模拟数据。
