# 国科二幼教学智能体本次更新说明

更新时间：2026-08-17（Asia/Shanghai；Chatflow 已发布，163 条资料新知识包的 13 个 Markdown 已在 Dify 原位替换且全部“可用”）

## 功能性修改

1. **增加教学需求分流**
   - 新增“教学需求路由”节点。
   - 完整教案、活动设计、年龄适配和教师话术进入“教学设计”分支。
   - 科学诗、科学故事、科学实验、步骤图、视频、二维码和详情页进入“资源与媒体”分支。
   - 删除旧的“用户输入直接连接知识检索”路径，避免一次提问重复检索。

2. **接入并分工使用 DeepSeek**
   - 路由节点与资源节点使用 `deepseek-v4-flash`，优先保证分类和资源响应速度。
   - 教学设计节点使用 `deepseek-v4-pro`，用于组织完整教案和分龄教学建议。
   - 两条分支使用同一公开科学教学资源库：教学设计检索 Top K 为 5，资源与媒体检索 Top K 为 10。

3. **修复公开对话中的推理内容泄露**
   - 在教学节点中开启“思考模式”参数覆盖并设为 `False`。
   - 开启“推理标签分离”，让公开页只显示最终回答，不显示模型内部推理过程。
   - 已重新发布 Chatflow，公开页实测不再出现长段“深度思考中”正文。

4. **保留资源同源跳转能力**
   - 资源回答会优先保持同一 `LAB/BASE` 下的视频、二维码和实验详情页。
   - 资源分支将 `p1.qr105.cn` 的 HTTP 视频地址改写为 HTTPS，避免 HTTPS 页面拦截。
   - 将资源检索 Top K 从 5 提升到 10，避免“全部步骤图、二维码、视频和详情页”组合请求只召回图片片段而遗漏相邻媒体片段。
   - 当前资料包共 163 条：科学诗 111 条、科学故事 28 条、科学实验 24 条。
   - 当前资料包中的《玩转纸片》条目为 `EXP-05b2527c3c7a`，二维码为 `e71f4d0fa45f3fc3.png`；新包已原位替换并全部显示“可用”，新建会话已复测视频、二维码、详情页和按序步骤图。

5. **完成新版知识库资料包迁移**
   - `dify/knowledge` 中除 `README.md` 外的 13 个 Markdown 已由当前 163 条资料导出；免费工作区按每次 1 个文件依次上传。
   - 13 个新版文件已在 Dify 原位替换旧包；文档列表仍为 2 页，没有重复旧包，且每个更新文档均显示“可用”。
   - 运行库现只保留新版 13 个 Markdown；资源类公开回答已按新版《玩转纸片》标识验收，旧版 160 条快照仅保留为历史记录。

6. **补齐 Word、PDF、PPT、Excel 的真实文件交付链路**
   - 新增“课件与文档创作”分类，和普通科学活动教案、资源查询分离。
   - `课件策划智能体` 使用 `deepseek-v4-pro` 生成可复制的 Word/PDF 正文或逐页 PPT 大纲。
   - `课件成稿审核智能体` 使用 `deepseek-v4-flash` 补齐教学结构、安全边界和年龄适配，并删除无依据的下载承诺和资源链接。
   - 课件与文档两条链路均按 DOCX、PDF、PPTX、XLSX 分流，由 Markdown Exporter 生成真实附件；每个回复只绑定对应工具节点的 `files`，不再把审核文本伪装成文件。

7. **补齐上传文档解析链路**
   - 新增“上传文档解析”分类和 `教学文件解析器 → 教研文档分析智能体 → 教研成稿审核智能体 → 格式路由 → 文件交付` 链路。
   - Dify 文件上传已开启，单次最多 3 个，支持图片和 TXT、PDF、DOC/DOCX、PPT/PPTX、XLS/XLSX 等文档。
   - 增加无敏感文本样例 `dify/fixtures/文档解析测试样例.txt`，用于发布前人工复测。

8. **修复完整教案缺少可点击详情页的问题**
   - 教学设计节点把“可以给出详情页”改为“命中明确 `LAB` 必须给详情页”。
   - 仅允许使用检索上下文中的真实 `LAB-ID`，避免根据标题猜测链接。
   - 《玩转纸片》回归测试应使用资料库返回的当前 `LAB`，本轮资料包对应 `https://www.qyfck.icu/lab?item=EXP-05b2527c3c7a`，不再硬编码上一版 ID。

9. **修复主教学节点没有真正读取资料库的问题**
   - 在“上下文”中选择 `知识检索 / result` 后，还在 SYSTEM 编辑器通过变量选择器插入了紫色内置“上下文”变量。
   - 移除了被当作普通文字的上下文残留，Dify 的“要启用上下文功能，请在提示中填写上下文变量”提示已消失。
   - 已在上一版 160 条知识快照中用公开会话验证按序步骤图和同一实验详情页；新版 13 个 Markdown 原位替换且全部“可用”后，已用新建会话验证 `EXP-05b2527c3c7a`、二维码 `e71f4d0fa45f3fc3.png`、4 张按序步骤图和同一实验详情页。

10. **明确图片输入边界**
   - 当前 `deepseek-v4-pro` 未启用图片识别。收到图片时，科小贝会明确请教师补充图中文字、材料名称、观察到的现象或实验步骤，再结合资料库给出建议。
   - 不再假装看见图片内容，也不识别或推断儿童身份、健康状况或其他隐私。

## 当前能力边界

- 当前 DeepSeek Chat 模型不能直接识别上传图片；需要教师补充图片中的文字或操作现象，不能把图片当作已识别内容。
- 上传文件解析链路已配置完成，但自动化浏览器不能向原生文件选择器写入路径；发布前应在 Dify 预览中手动上传 `dify/fixtures/文档解析测试样例.txt` 完成一次无敏感端到端复测。
- 重新导出知识库前，应先完成导出包中的班级和署名脱敏审计，再上传 Dify，避免将个人或班级标识带入云端。本轮 163 条导出包已通过邮箱、手机号、身份证号、微信/QQ、班级和署名模式扫描。
