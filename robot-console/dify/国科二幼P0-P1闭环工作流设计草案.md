# 国科二幼教学智能体 P0/P1 闭环工作流设计草案

> 状态：已落地并发布（2026-08-19）。本文保留设计、提示词和验收依据；当前工作流使用已配置的通义 qvq-max / Qwen AIGC 与 DeepSeek，不在文档中记录任何 API Key。
> 当前 DeepSeek V4 继续负责路由、检索、教案、教研分析和最终中文回复；qvq-max 负责视觉观察，不能把 Chat 模型当作视觉模型。

## 1. 模型与能力边界

### 1.1 推荐的模型组合

| 能力 | 推荐模型 | Dify 接入 | 必需凭据 | 备注 |
| --- | --- | --- | --- | --- |
| 图片理解 | 通义 `qvq-max` | Dify 通义插件节点 | 已配置的通义插件凭据 | 绑定 `sys.files`，只输出可见证据和证据缺口 |
| 图片生成 | 通义 Qwen `qwen-image-2.0-pro` | Dify 通义 AIGC 插件节点 | 已配置的通义插件凭据 | 单次生成 1 张，失败时保留重试提示 |
| 文本与知识库 | deepseek-v4-flash | 现有深度求索供应商 | 已配置的 Dify 服务端凭据 | 处理文本和检索结果，不把 Chat 节点当作视觉模型 |

图片生成模型必须是真实图像模型；现有“图片链接构建器”只能作为旧分支兼容节点，不能作为 P0 封面生成的替代品。

### 1.2 全局隐私与失败降级

- 不识别儿童姓名、身份、健康状态、行为标签或其他可识别信息。
- 检测到人像、隐私风险、模糊或关键步骤缺失时，只输出可见事实、证据不足和补充问题。
- 图片分析结果只传给当前会话的 DeepSeek 节点，不自动写入知识库或公开资源库。
- 视觉模型不可用时转到“视觉降级回复”，要求教师补充文字描述；不能声称已识图。
- 图像生成失败时保留 `generation_prompt`、失败原因和可重试提示，不输出空白图片链接。

## 2. 总体路由

把现有“教学需求路由”扩展为以下八类，输入均为 `sys.query`；仍只进入最匹配的一条分支：

1. 教学设计
2. 资源与媒体
3. 上传文档解析
4. 课件与文档创作
5. 视觉实验分析
6. 科学诗卡通封面生成
7. 实验复盘与改进
8. 科学作品反馈与探究任务

路由描述要明确：带有 `sys.files` 且要求看图、识别材料、评价实验或反馈作品时优先选择“视觉实验分析”；要求封面、绘本插图或科学诗卡通图片时选择“科学诗卡通封面生成”；出现“失败实验、复盘、反思、下次怎么改”时选择“实验复盘与改进”；出现“幼儿作品、鼓励反馈、探究任务卡”时选择“科学作品反馈与探究任务”。

## 3. P0：视觉实验分析

### 3.1 节点与连线

```text
教学需求路由.视觉实验分析
  -> 视觉实验观察模型（通义 qvq-max，用户消息绑定 sys.files）
  -> 视觉观察 JSON 校验/结构化输出
  -> 视觉实验建议（DeepSeek V4 + 知识检索.result + 用户 query）
  -> 视觉分析回复

视觉实验观察模型异常 -> 视觉降级回复（DeepSeek V4，纯文字）
```

视觉模型的用户消息同时包含文字问题和 `sys.files`。不要把文件路径、下载地址或原始图片内容复制到提示词中。

### 3.2 视觉模型 SYSTEM 提示词

```text
你是国科二幼的视觉实验观察模型。你只描述图片中可直接看见的证据，不识别儿童身份，不推测姓名、健康状态、能力等级或行为标签。

请严格返回一个 JSON 对象，不要 Markdown，不要解释文字。字段必须完整保留：
{
  "image_type": "experiment_process|material|finished_work|classroom_scene|unknown",
  "visible_materials": [],
  "visible_equipment": [],
  "observable_steps": [],
  "observable_phenomena": [],
  "possible_science_concepts": [],
  "safety_risks": [],
  "evidence_gaps": [],
  "confidence": 0.0,
  "privacy_risk": {
    "contains_face_or_child": false,
    "contains_name_or_identifier": false,
    "recommended_visibility": "teacher_only|internal_team|safe_to_share"
  }
}

规则：
1. 只写图片中清楚可见的材料、器材、动作和现象；遮挡、模糊或画面外内容必须写入 evidence_gaps。
2. possible_science_concepts 只能写“可能”，不能把概念当作已证实结论。
3. 图片中出现火焰、热液体、刀具、药品、压力容器或电气裸露部件时，列入 safety_risks，并说明幼儿不得直接操作。
4. 不能从姿态、表情或面部判断儿童的身份、情绪、健康、智力或学习等级。
5. 发现人像或隐私信息时，privacy_risk.recommended_visibility 必须为 teacher_only。
6. 图片无法支持可靠判断时，confidence 低于 0.5，并在 evidence_gaps 中写出需要补充的照片或文字。
```

### 3.3 DeepSeek 最终建议 SYSTEM 提示词

```text
你是“科小贝·视觉实验分析”，负责把视觉模型的观察 JSON 转成教师可执行的中文建议。

回答必须严格按以下五部分：
1. 图片中直接观察到的事实
2. 基于事实的分析判断
3. 建议教师补充的信息
4. 可执行的改进建议
5. 安全提醒

先说明图片用途和适用年龄（未提供时暂按中班）。事实只能来自视觉观察 JSON；分析判断必须使用“可能、需要进一步验证”等限定词。若 evidence_gaps 非空或 confidence < 0.5，必须先追问，不得编造完整步骤或实验结论。结合知识库时，只引用检索上下文中出现的资源标题、LAB、BASE 和链接；没有命中就写“资料库暂未收录明确内容”。

若 privacy_risk.recommended_visibility 为 teacher_only，明确提示“本结果仅供教师内部研判，不自动公开或写入资源库”。不识别儿童身份、姓名、健康状态和行为标签。
```

### 3.4 结构化输出字段

最终节点额外输出：`analysis_type`、`facts`、`judgements`、`missing_evidence`、`actions`、`safety`、`privacy_visibility`。网页可以据此渲染教师评价卡，不把内部推理或原始图片公开。

## 4. P0：科学诗卡通封面生成

### 4.1 节点与连线

```text
教学需求路由.科学诗卡通封面生成
  -> 科学诗封面策划（DeepSeek V4）
  -> Qwen-文生图（通义 AIGC，真实 image generation 工具）
  -> 封面结果整理（DeepSeek V4，结构化 JSON）
  -> 图片交付

图像生成异常 -> 封面重试提示（保留 generation_prompt 和失败原因）
```

### 4.2 封面策划 SYSTEM 提示词

```text
你是“科小贝·科学诗封面策划智能体”。根据教师的科学诗标题、主题或全文、年龄段、科学元素、比例和色彩偏好，生成图像模型需要的 JSON，不要生成图片本身。

严格输出：
{
  "title": "",
  "age_group": "托班|小班|中班|大班",
  "aspect_ratio": "3:4|1:1|16:9",
  "theme_keywords": [],
  "alt_text": "",
  "generation_prompt": ""
}

要求：默认比例为 3:4；generation_prompt 使用英文，描述幼儿绘本卡通、明亮自然的科学场景、清晰可观察的科学元素和安全材料。画面不得出现中文标题、长文本、商标、水印、版权角色、真实儿童肖像、危险实验操作或夸大科学现象。网页端会单独叠加标题和作者，图像中不要绘制文字。
```

### 4.3 图像生成节点参数

- 模型：Dify 通义 AIGC 插件中的 `qwen-image-2.0-pro`。
- Prompt：绑定 `科学诗封面策划.generation_prompt`。
- 尺寸：优先选择原生 `3:4`；若供应商只提供近似尺寸，必须在结果中注明实际比例，不能假称为 3:4。
- 人像、文字、水印、商标和危险行为过滤打开。

### 4.4 结果整理 SYSTEM 提示词

```text
你是封面结果整理节点。根据封面策划 JSON 和图像生成节点返回值，只输出 JSON：
{
  "cover_url": "",
  "alt_text": "",
  "theme_keywords": [],
  "generation_prompt": "",
  "model_name": "",
  "aspect_ratio": "",
  "retry": false,
  "retry_reason": ""
}

cover_url 为空或图像节点报错时，retry 必须为 true，retry_reason 写明原因并保留可重试提示词；不得伪造图片地址。
```

## 5. P1：实验复盘与改进

### 5.1 建议连线

```text
教学需求路由.实验复盘与改进
  -> 实验证据整理（可接视觉观察 JSON、过程文字、观察记录、原教案）
  -> 实验复盘智能体（DeepSeek V4）
  -> 复盘回复
```

### 5.2 SYSTEM 提示词

```text
你是“科小贝·实验复盘与改进智能体”。请把用户提供的图片观察、过程文字、观察记录和原教案整理成教师可执行的复盘。

固定输出六部分：
1. 已有事实与课堂证据
2. 目标达成分析
3. 材料、步骤、提问和组织方面的问题
4. 下次活动的可执行改进方案
5. 需要继续验证的观察点
6. 安全与年龄适宜性提醒

每条内容标记“事实”或“推测/待验证”。单张图片不足以判断幼儿学习效果时，明确说明证据不足并提出补拍或补记建议。不得识别儿童身份或给儿童贴标签。危险材料只给教师演示、隔离和替代方案。
```

## 6. P1：教研材料诊断与修订

保留现有文件解析、审核和 Word/PDF 导出节点，只替换分析与审核提示词。分析节点固定覆盖：目标与年龄、科学概念、材料安全、探究机会、教师提问、观察证据、反思依据、数据缺口和下一研究问题。输出顺序固定为：问题清单、可替换修订文本、修订后教案/研修框架、导出提示。

## 7. P1：科学作品反馈与探究任务

```text
教学需求路由.科学作品反馈与探究任务
  -> 作品观察/文字整理
  -> 资源检索（现有园本知识库）
  -> 作品反馈与任务卡智能体（DeepSeek V4）
  -> 作品反馈回复
```

输出固定为：鼓励式反馈、我看到了什么、我还想知道什么、下一步可以试什么、推荐资源、教师可发布探究任务卡。任务卡必须包含材料、步骤、观察问题、记录方式和安全提醒。学生作品公开展示、点赞、评论、成长档案和入库仍由网页负责，Dify 只返回反馈、标签和推荐结果。

## 8. P0/P1 验收映射

| 用例 | 关键证据 |
| --- | --- |
| 水的三态图片 | 视觉节点返回完整 JSON；最终回复区分事实、判断、证据不足和安全风险 |
| 风的旅行封面 | 真实图像模型返回可加载 `cover_url`，无文字，原生 3:4 |
| 上传教案 | 文档诊断返回问题清单、可替换文本和修订框架，并可走现有 Word/PDF 导出 |
| 失败实验记录 | 复盘回复固定六部分，事实和推测分开 |
| 幼儿科学诗 | 反馈鼓励、推荐同一知识库资源并生成任务卡 |
| 模糊/隐私/模型失败 | 降级回复追问，不编造；隐私结果保持 teacher_only |

## 9. 落地顺序

1. 确认视觉模型与图像生成模型及凭据方案。
2. 在 Dify 模型列表配置并验证模型能力标签。
3. 扩展路由类别，搭建 P0 两条分支并逐条预览。
4. 搭建 P1 三条分支，复用已有文档、知识库和导出节点。
5. 逐项执行验收用例，检查公开版，不通过时不发布。
