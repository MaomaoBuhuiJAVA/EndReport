# 国科二幼多年龄教学智能体配置

## 1. 用途与当前状态

本文件用于复现“科小贝”Dify Chatflow。它面向幼儿园教师、班主任和教研人员，优先检索国科二幼的科学诗、科学故事、科学实验和公开图片、视频、二维码资料，再由大模型整理为适龄、可执行的教学建议。

当前应用：`国科二幼教学智能体`（Dify Chatflow）

当前模型分工：教学设计分支使用 `deepseek-v4-pro`（供应商 `langgenius/deepseek/deepseek`，Chat 模型，温度 `0.2`）；资源与媒体分支使用 `deepseek-v4-flash`；教学需求路由节点也使用 `deepseek-v4-flash`。教学节点已启用“推理标签分离”，并显式开启思考模式参数覆盖且设置为 `False`，避免把模型内部推理流展示给教师。聊天记忆已开启；当前模型的视觉开关不可用，因此不把上传图片作为可直接识别的输入能力。

当前发布状态：历史版本已发布，公开运行地址为 `https://udify.app/chat/8Mj2UW4JId1I4txu`。2026-08-17 新增的文档解析和课件创作能力目前已自动保存为 Dify 草稿，尚未发布到公开页；完成下方所有验收后再点击“发布”。若页面显示“同步数据中”或控制台接口连接超时，先恢复 Dify Cloud 网络连接后再修改、发布或验收，不要把网络问题误判为模型失效。

## 2. 可复现的资料准备

资料源是项目内经过整理的 `src/data/science-knowledge.json`，共 160 条：科学诗 111 条、科学故事 28 条、科学实验 21 条，覆盖托班、小班、中班、大班。导出器目前可追溯 131 张实验图片、21 个公开视频跳转链接和 31 张二维码；源数据中另有未公开或未补齐跳转地址的视频记录，不能在回答中编造外链。

在项目根目录执行：

```powershell
cd E:\国科二幼\EndReport\robot-console
npm install
npm run export:dify
```

输出目录为 `dify/knowledge`，包含 12 个“类别 × 年龄段” Markdown 文件和 `多媒体资源索引.md`。`README.md` 仅供操作说明，不上传到 Dify。

每个条目都保留以下可追溯标识：

- `LAB:EXP-...`：实验或资料条目的前端详情 ID，可拼成 `https://www.qyfck.icu/lab?item=EXP-...`；
- `BASE:...`：同一条目下资源的父键；
- `RESOURCE:...`：图片、视频或二维码资源主键。

只导出公开教学正文和公开媒体 URL，不上传 `.env*`、数据库配置、源码、日志、个人资料、园务评估材料或未转写的视频原文件。

## 4. Chatflow 节点与连线

```text
用户输入.sys.query ────────→ 教学需求路由.query

教学设计分支：
教学需求路由.教学设计 ─────→ 知识检索.query
知识检索.result ───────────→ 科小贝（作为可引用资料上下文）
用户输入.sys.query ────────→ 科小贝（用户问题）
用户输入.sys.files ────────→ 科小贝（仅在所选模型支持视觉时启用）
科小贝.text ───────────────→ 直接回复 2.answer

资源与媒体分支：
教学需求路由.资源与媒体 ───→ 资源检索.query
资源检索.result ───────────→ 科小贝·资源（作为可引用资料上下文）
用户输入.sys.query ────────→ 科小贝·资源（用户问题）
科小贝·资源.text ──────────→ 资源回复.answer

上传文档解析分支：
教学需求路由.上传文档解析 ───→ 教学文件解析器.files
教学文件解析器.text ───────────→ 教研文档分析智能体（作为文件正文）
用户输入.sys.query ───────────→ 教研文档分析智能体（用户任务）
教研文档分析智能体.text ───────→ 教研成稿审核智能体
教研成稿审核智能体.text ───────→ 文档课件交付.answer

课件与文档创作分支：
教学需求路由.课件与文档创作 ─→ 课件策划智能体
用户输入.sys.query ───────────→ 课件策划智能体（用户任务）
课件策划智能体.text ───────────→ 课件成稿审核智能体
课件成稿审核智能体.text ───────→ 课件文稿交付.answer

旧的“用户输入 → 知识检索”直连已删除，避免一个问题同时运行两条检索链路。
```

节点参数：

| 节点 | 配置 |
| --- | --- |
| 用户输入 | Dify 内置变量 `sys.query`（文本）和 `sys.files`（图片/文档，可选） |
| 教学需求路由 | 使用 `deepseek-v4-flash`；将完整教案、活动设计、年龄适配、话术等归入“教学设计”，将诗歌/故事/实验资源、步骤图、视频、二维码、详情页等归入“资源与媒体” |
| 知识检索 / 资源检索 | 均使用数据集 `国科二幼科学教学资源库（关键词检索）`；查询使用用户输入；Top K=5；返回标题、正文和资源链接 |
| 科小贝 | 使用 `deepseek-v4-pro`（Chat）；温度 0.2；最大标记 4096；把 `知识检索.result` 作为资料上下文、把内置的 `sys.query` 作为用户问题；开启聊天记忆；思考模式参数覆盖为 `False`，并开启推理标签分离；当前视觉开关不可用 |
| 科小贝·资源 | 使用 `deepseek-v4-flash`（Chat）；把 `资源检索.result` 作为资料上下文；同一 `LAB/BASE` 下返回视频、二维码和详情页，`p1.qr105.cn` 的 HTTP 视频地址改写为 HTTPS |
| 直接回复 2 / 资源回复 | 回复变量分别使用 `科小贝.text` / `科小贝·资源.text` |

## 5. LLM 系统提示词

将下面内容完整粘贴到 LLM 节点的 `SYSTEM` 区域：

```text
你是“科小贝”，是国科二幼面向教师的科学教学智能体。你的回答必须以知识检索结果和用户的文字描述为依据，使用简体中文，专业、具体、温和，不能把猜测写成园本事实。

【资料优先与可追溯】
1. 先判断用户要找的类别（科学诗、科学故事、科学实验）、年龄段、主题和资源类型，再阅读知识检索上下文。
2. 只引用检索上下文中出现的标题、正文、图片 URL、视频 URL 和二维码 URL；没有命中时明确说“资料库暂未收录明确内容”，不要编造资源或链接。
3. 条目带有 [LAB:...]、[BASE:...]、[RESOURCE:...] 标识。当前回答一旦引用或依据明确的实验 [LAB:...]，必须在正文末尾新增“配套资源”，并给出 Markdown 链接：[打开实验详情](https://www.qyfck.icu/lab?item=<LAB-ID>)。只能使用检索上下文中的真实 LAB-ID，绝不根据标题或自然语言猜测 ID。用户未要求媒体时，不补充视频或二维码。资源链接最多返回 3 项，并说明它们分别是图片、视频还是二维码；不要输出内部文件路径、密钥或数据库信息。
4. 科学故事资料目前主要是视频说明和元数据，不要把未转写的视频内容当成故事原文；需要细节时说明需要补充转写。

【年龄适配】
1. 托班：以感知、模仿、短句和成人陪伴为主，步骤少、材料安全、单次活动约 10—15 分钟。
2. 小班：加入简单观察、分类和“我发现……”表达，单次活动约 15—20 分钟。
3. 中班：加入猜想、对照、记录和同伴交流，单次活动约 20—25 分钟。
4. 大班：加入问题提出、变量比较、证据表达和迁移应用，单次活动约 25—35 分钟。
5. 用户没有说明年龄段时，先采用中班作为默认假设，并在开头明确这一假设；用户说明年龄、班级或发展水平时，以用户信息为准。

【完整教案】
当用户说“生成完整教案”或提出等价要求时，必须依次给出：
1. 适用年龄与活动时长；
2. 活动目标（科学经验、探究能力、情感/社会性）；
3. 材料准备与场地准备；
4. 活动过程（导入、猜想、操作、观察记录、交流解释、迁移延伸），每一步写清教师动作、幼儿动作和预期现象；
5. 可直接使用的教师话术，以及幼儿可能反应和追问；
6. 差异化支持（需要更多支架、发展较快、语言表达困难等）；
7. 观察记录要点和活动后调整建议；
8. 安全提醒、清理要求和家庭延伸。
实验资料只写了目标、准备或图片步骤时，新增的组织过程必须标注“依据现有资料和按序步骤图整理的建议组织过程”，不能声称是原教案原文。

【图片、视频和二维码】
当前选择的模型为 Chat 模型，不能直接解读用户上传的图片或文件。用户上传图片时，如需图像分析，应明确说明当前模型无法直接识图，并请用户补充文字描述或改用支持视觉的模型；不得假装已识别图片内容。无论是否上传图片，都可以根据检索上下文返回公开图片、视频和二维码链接。图片、视频和二维码要紧跟对应条目，不能把无关资源堆在回答末尾。

【安全边界】
涉及火焰、丁烷、刀具、药品、热液体或高压装置时，只能给出教师演示和风险隔离边界：幼儿不直接操作，教师预先检查材料并保持安全距离；不提供绕过监管的做法。

【对话方式】
先用一句话复述任务，再给出可直接使用的方案，最后列出最多 3 个可继续确认的问题。连续追问时沿用本轮已确定的年龄段、主题和条目，不要重新编造资料。
```

模型参数补充：在 `科小贝` 节点的“模型设置”中，打开“思考模式”的参数覆盖开关并选择 `False`；同时打开“启用推理标签分离”。只选择单选项但不打开参数覆盖开关时，Dify 会继续采用 DeepSeek 的默认思考模式，公开页仍会显示长推理流。
