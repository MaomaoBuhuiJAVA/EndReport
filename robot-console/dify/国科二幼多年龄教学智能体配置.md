# 国科二幼多年龄教学智能体配置

## 1. 用途与当前状态

本文件用于复现“科小贝”Dify Chatflow。它面向幼儿园教师、班主任和教研人员，优先检索国科二幼的科学诗、科学故事、科学实验和公开图片、视频、二维码资料，再由大模型整理为适龄、可执行的教学建议。

当前应用：`国科二幼教学智能体`（Dify Chatflow）

当前模型分工：教学设计分支使用 `deepseek-v4-pro`（供应商 `langgenius/deepseek/deepseek`，Chat 模型，温度 `0.2`）；资源与媒体分支使用 `deepseek-v4-flash`；教学需求路由节点也使用 `deepseek-v4-flash`。教学节点已启用“推理标签分离”，并显式开启思考模式参数覆盖且设置为 `False`，避免把模型内部推理流展示给教师。聊天记忆已开启；当前模型的视觉开关不可用，因此不把上传图片作为可直接识别的输入能力。

当前发布状态：2026-08-17 19:36（Asia/Shanghai）已在 Dify 发布当前 Chatflow，公开运行地址为 `https://udify.app/chat/8Mj2UW4JId1I4txu`。本次发布除保留文档解析和课件创作的四类附件交付、单附件回复、检索上下文修复和媒体召回优化外，还修复了“上传文档但未指定导出格式”被错误拦截为格式追问的问题：该分支现在直接返回 `教研成稿审核智能体.text`，并在末尾提示可选导出格式；无上传文件的课件创作分支仍按原逻辑追问格式。当前工作区已生成 163 条资料的新知识包；新版 13 个 Markdown 已在 Dify 原位替换旧包，文档列表仍为 2 页、没有重复旧包，且每个更新文档状态均为“可用”。新建公开会话已完成新版资源回归：返回 `EXP-05b2527c3c7a` 的详情页、4 张按序步骤图、HTTPS 视频和二维码 `e71f4d0fa45f3fc3.png`，完整教案也带有详细活动过程。若页面显示“同步数据中”或控制台接口连接超时，先恢复 Dify Cloud 网络连接后再修改、发布或验收，不要把网络问题误判为模型失效。

### 4.2 课件附件内容格式

`课件策划智能体` 和 `课件成稿审核智能体` 共同遵循以下交付约束：

- DOCX/PDF：输出原始 Markdown，使用标题、二级标题、列表和必要表格，不包裹外层 Markdown 代码围栏；
- PPT/PPTX：封面为一级标题；从第 1 页起以同级二级标题表示每页，页面之间用三个连字符分隔；每页包含屏幕文字、配图/版式建议、教师互动提示和必要安全提醒，不使用跨页表格；
- XLSX：只输出一个或多个列数一致的 Markdown 表格，首行作为字段标题，不在表格前后添加解释性段落；
- 两节点都不得声称“无法导出”或承诺未生成的下载链接。实际附件只由下游 Markdown Exporter 生成并通过对应的 `files` 字段返回。

如果 Dify 版本将知识库作为 LLM 的“上下文”而不是独立节点，选择同一数据集并保持 Top K、相关度和提示词不变，等价于上面的连线。
