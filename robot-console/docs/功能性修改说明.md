# 功能性修改说明

更新日期：2026-08-16

本文记录本轮上线前完成的用户可见功能调整，以及相关资料的维护方式。

## 1. 省二级评估自评报告替换

- 资料库中原先删除的省二相关文章已替换为《国科第二幼儿园省二级评估自评报告》。
- 新报告以 WPS 原始文件保存，并可提取完整正文、生成资料卡片、详情弹窗内容和智能体检索分块。
- 部署时仅对这一份报告执行新增或更新，不会清理资料库中的其他文章；重复部署会更新同一条记录，不产生重复资料。
- 资质类提问会优先检索这份报告，并限制关键词数量，避免长问题触发检索回退；旧《省二终极》记录已清理。

## 2. 资料名称展示清理

- 园所资料卡片、资料详情和接口返回内容会自动隐藏导入文件名末尾重复的版本标记，例如 `(1)`、`（1）`、`(定稿)`、`（定稿）`。
- 此调整只影响网页显示，不会修改原始资料文件或资料正文的实际内容。

## 3. Coze 智能体工作流与中文对话

- 智能体采用 Coze 智能体的角色设定、知识优先和多轮对话工作流：每次提问会先检索园所资料库和科学资源库，再将检索结果与最近对话上下文交给底层大模型生成中文回复。
- 智能体将模型调用封装在服务端工作流中，资料检索、来源展示和实验详情跳转由平台统一控制，可根据部署环境灵活调整模型服务。
- 保留原有资料库检索能力：模型回答仍以检索到的资料为依据，不把模型回答替换为脱离资料库的自由问答。
- 当模型未配置、请求超时或服务暂时不可用时，系统会自动回退到原有的资料库检索回答，确保基本问答不中断。
- 原有的功能室照片匹配和资料来源展示继续保留。

## 4. 对话结果直达实验详情

- 用户在智能体中询问到科学实验、科学诗或科学故事时，回答下方会给出对应的“查看《资料名称》”入口。
- 点击入口后会打开实验室页面，并直接弹出该资料的详情窗口，无需再次搜索或在列表中查找。
- 弹窗支持关闭、遮罩点击关闭和 Esc 键关闭；手机端与桌面端使用同一交互逻辑。

## 5. 科小贝实验室资源中心

- 实验室页面按“科学诗、科学故事、科学实验”分类展示资源，并提供主题、年龄段和关键词筛选。
- 补入本地科学资源库中的公开图片、实验步骤、作者、来源和正文摘要。
- 页面优先读取生产数据库；当数据库暂时没有对应资源，或存在缺少视频、二维码等资源的旧记录时，会自动补齐随代码发布的科学资源清单，同时保留数据库中的正文与人工修改，避免部署后出现空白或缺失资源。

## 6. 封面与实验步骤图片

- 实验列表封面会使用该实验的第一张有效公开图片。
- 实验详情弹窗会在正文下方按“图片 1、图片 2、图片 3……”的数字顺序展示步骤图片，并带有连续步骤编号。
- 图片筛选仅保留公开的“图片资源”；二维码、视频和其他资源不会混入实验步骤图片序列。

## 7. 视频跳转与二维码

- 为 21 个科学实验恢复了已有的视频跳转地址。
- 每个实验详情弹窗都提供“播放视频”按钮，在新页面打开对应视频。
- 每个视频同时提供二维码，扫码和按钮打开的是同一地址；二维码静态文件位于 `public/science-assets/video-qr/`，会随 Vercel 部署发布。
- 资源区域在小屏幕下改为纵向排列，保证视频按钮和二维码都能正常查看和点击。

## 8. 本轮试用反馈针对性调整

- 首页收束为“科小贝智能体”入口，保留实验室和少量园所资料入口；首页“开始对话”与实验室使用同一个科小贝对话窗口。
- 对话窗口改为完整历史可滚动布局，向服务端发送最近 12 条消息；问候、感谢和能力询问会直接进入自然对话，不会误带无关实验来源或跳转链接。
- 输入“生成《玩转纸片》完整教案”时锁定当前实验资料，输出活动目标、活动准备、活动过程、观察表达、小结延伸和活动提示；资料中的“实验步骤”分隔标记不会再混入活动过程列表。
- 对话命中的科学资源使用“查看《资料名称》”入口，点击后直接打开 `/lab?item=...` 对应详情弹窗；无效资源 ID 会显示明确提示。
- 实验室支持全部类型、主题、年龄段和关键词组合筛选；《会变色的小水滴》展示主题校正为“水科学与气象自然”，实验步骤图片按图片编号顺序展示，视频链接和二维码按资源记录显示。
- 关键词搜索会叠加当前选定的类型、主题和年龄段；未选择分类时仍可进行全库搜索，避免检索结果混入不相关栏目。
- 完整教案只有同时包含活动目标、活动准备、活动过程、观察表达、小结延伸和活动提示时才采用模型结果；任一部分缺失会自动使用当前实验资料补齐完整结构。
- “今天天气真好”“讲个笑话”等纯闲聊不再触发资料检索或附带实验跳转；包含“推荐实验”“找资料”等明确任务的提问仍会正常检索。

## 维护方法

视频地址新增或变化时，先更新本地资料库中对应学期的 `视频资源/README.md`，再在 `robot-console` 目录执行：

```powershell
npm run attach:science-videos
npm run test:science
```

需要同步生产数据库时，再执行：

```powershell
npm run seed:science
```

最后从仓库根目录执行 Vercel 生产部署，避免将项目根目录重复拼接：

```powershell
npx vercel --cwd "E:\国科二幼\EndReport" --prod
```
