# 账号头像菜单

首页、资源库和作品页复用 `AccountMenu`。服务端传入当前账号，登录后直接显示头像；未登录显示登录入口。手机宽度下菜单移至独立浮层，避免被页面原有的隐藏页头样式遮住。

菜单提供修改登录用户名、修改昵称、系统头像或上传图片、修改密码、手机换绑、作品档案、管理员审核入口和退出登录。五项账号修改均在当前页面的原生模态弹窗内完成，保存后刷新账号资料，页面地址保持不变。用户名与密码修改要求当前密码；更换手机要求当前手机及新手机的短信验证码，首次绑定要求账号密码及新手机验证码。原有独立账号设置页面继续可用。

桌面宽度下，鼠标悬停头像展开菜单，移入菜单保持展开，离开时延迟淡出；手机宽度下使用点击展开，避免悬停与点击冲突。菜单与弹窗支持键盘、Escape、返回头像焦点及减少动态效果的系统偏好。敏感表单关闭后清除，验证码仍使用已有阿里云短信接口与服务端校验。

登录页使用密码登录、验证码登录两个页签，保留独立注册入口，移除验证码登录标题和未发送时的说明。密码登录、验证码登录和已创建会话的注册均直接跳转 `/lab`；已登录用户访问普通 `/auth` 也直接进入资源库。

资料接口只更新当前会话账号，并检查会话版本和同源请求。头像上传限 3 MB，验证实际解码格式为 JPEG、PNG 或 WebP，裁成 192×192、去除原图元数据并保存为不超过 64 KB 的 WebP。头像图像不放进会话 cookie，读取接口要求当前会话且禁止共享缓存。
