# 接龙反馈整改说明

本次根据教师和使用者提出的 8 条接龙意见，对“科小贝”首页、对话、科学资源库和实验详情进行了针对性调整。调整范围只保留与科小贝使用流程直接相关的入口，原有园所资料和知识库检索能力继续保留在后台。

## 一、反馈对应的功能修改

### 1. 首页突出科小贝

- 首页主视觉改为“科小贝智能体”简介和“开始对话”入口。
- 保留“科小贝实验室”资源库入口，移除首页冗长的旧资料卡片和无关导航。
- 移动端导航只保留“科小贝”和“资源库”，减少层级和视觉干扰。

对应反馈：林漪、凸显科小贝部分，其他功能过于冗长。

### 2. 对话窗口和闲聊能力

- 对话窗口改为可用的完整视口高度，移动端不再只显示半截面板。
- 普通问候、天气、笑话、自我介绍和“随便聊聊”等内容不再被误判为资料检索，科小贝会连续回应。
- 仍保留资料库检索：涉及实验、故事、科学诗、教案、年龄段或园所资料时，继续优先检索本地知识库。
- 对话请求继续将历史消息传给大模型，保留上下文对话能力。

对应反馈：翁梦瑶、张雪。

### 3. 完整教案和相关资源

- 识别“生成《主题》完整教案”请求，并锁定当前主题资料。
- 教案固定检查并输出“活动目标、活动准备、活动过程、观察与表达、小结与延伸、活动提示”等部分；资料正文缺少活动过程时使用可执行的兜底过程，避免只返回目标和准备。
- 教案下方只生成当前主题的实验详情链接，不再堆叠无关实验资源。
- 点击“查看《主题》”进入 `/lab?item=<资源ID>`，资源库页面会自动打开对应详情弹窗。

对应反馈：唐依慧、周倩倩。

### 4. 实验步骤图片、视频和二维码

- 为原目录中缺少网页图片的 10 个实验补挂本地步骤图，并将图片发布到 `public/science-assets/experiments/`；对新目录中 4 张重复透明过渡图不进入展示序列。
- 新实验图片按“材料准备 → 操作步骤”分组，并按数字自然排序；标题显示为“材料准备 1”“操作步骤 1”，视频二维码不混入步骤序列。
- 21 个实验保留资料库中的真实视频链接，并逐张显示素材目录中的二维码；多二维码实验不会丢失后续二维码。
- 故事类视频目前只有本地归档文件而没有公开播放地址，页面明确显示“暂未提供在线播放链接”，不虚构外部地址。

对应反馈：翁梦瑶、妙妙😊。

### 5. 检索、筛选和分类

- 支持中文连写检索，例如“小班水实验”“科学实验小班水与液体”“小班光学故事”。
- 类型、主题、年龄段筛选保持“类型 → 主题 → 年龄段”结构；主题和年龄段允许保持“全部”，避免被锁进内容稀疏的组合。
- 修正《会变色的小水滴》的展示主题为“水科学与气象自然”，同时保留原始来源路径，避免混入“动物生活习性认知”。
- 资源库空结果会显示明确提示，可切换筛选条件或更换关键词。

对应反馈：妙妙😊。

## 二、可复现方式

在 `E:\国科二幼\EndReport\robot-console` 执行：

```powershell
npm run attach:science-step-images
npm test -- app/api/ai-chat/route.test.ts
npm run test:science
npm run lint
npx tsc --noEmit
npm run build
```

`attach:science-step-images` 是幂等脚本：重复执行时只会补齐缺图，不会重复添加同一批资源。科学目录、对话接口和组件契约测试分别覆盖检索、分类、步骤图、视频二维码、详情跳转和完整教案。

本地预览：

```powershell
npm run dev
```

打开 `http://127.0.0.1:3000/`，点击“开始对话”；也可直接打开 `http://127.0.0.1:3000/lab?item=EXP-0a9be04a415a` 查看详情弹窗。

## 三、发布后验收重点

- 首页能看到科小贝简介和对话入口。
- 对话生成完整教案时包含活动过程，并只显示当前主题资源链接。
- 资源链接能打开对应实验详情弹窗。
- 实验详情按顺序显示步骤图、视频按钮和二维码。
- `/api/science-resources` 返回资源列表，`/api/ai-chat` 能返回对话和实验详情链接。
