# 科小贝的动手科学馆

本地入口 `/games`。模块沿用现有 Next.js 项目，现开放磁力打捞、沉浮实验、影子工坊三款实际操作小游戏。旧版磁铁“会吸住／不会吸住”预测问答已替换；孩子通过拖动物体、观察结果完成探索。成长页、头像和游戏入口使用统一的科学馆视觉。

游戏进度保存在当前浏览器，运行三款游戏不依赖数据库，不需要新增环境变量。Matter.js 0.20.0 用于磁铁和水槽的运动、碰撞与约束；影子工坊的光线投影由本项目实现。

## 页面与玩法

| 页面 | 当前行为 |
|---|---|
| `/games` | 三款可直接进入的游戏、当日完成标记、本周积分、成长与探索榜入口 |
| `/games/play/magnet` | 拖动红色磁铁吸起铁钉、铁质回形针、铁螺母、铁垫圈、铁螺栓，送到左上盘子后松手；五件全收集即完成。木块、塑料积木、铝罐不被磁力吸附 |
| `/games/play/water` | 拖动松木块、实心钢球、橡皮泥球、橡皮泥船入水，松手观察稳定沉浮；四件均观察后完成。球与船的橡皮泥质量相同，球下沉、保持船口朝上的船漂浮 |
| `/games/play/shadow` | 拖动小球或上下移动灯，让墙面影子填入目标框；依次完成变大、变小、移动到下方三关。对准后松手并保持约 650 毫秒通过该关，第三关通过后完成 |
| `/games/leaderboard` | 当前浏览器档案的周榜，按年龄段查看、同分并列；未得分档案显示为尚未上榜 |
| `/games/growth` | 添加／编辑昵称、年龄与三种头像，切换孩子档案，查看各自积分、主题徽章和最近记录 |
| `/games/artwork` | 美术素材需求、尺寸、文件名、提示词及有效文件状态 |
| `/api/games/artwork` | 只检查美术清单中的固定文件路径 |

种子主题仍未开放。三款游戏支持重新开始，完成区可再玩或切换实验；重玩不重复增加同日积分。拖动取消、失去焦点和页面切换时清理当前手势，返回后可以继续操作。磁铁有吸附／入盘反馈，水槽有落水与观察反馈。键盘辅助：磁铁方向键移动、空格／回车放下；水槽 1—4 选物体、方向键移动、空格松手；影子 1 选球、2 选灯、方向键移动。

这些是面向幼儿的简化模拟：磁力不精确求解真实磁场；浮力使用二维排水面积近似，船保持朝上且暂不模拟进水；影子使用点光源、不透明球与竖直屏幕，按球的两条切线计算投影，不模拟复杂光源和半影。

## 本地档案与积分

存储键为 `kexiaobei.science-games.v1`。每个孩子、每款游戏、每个北京时间日期首次完成 +10 分，三款合计每天最多 30 分。未完成不计分，重新摆放不撤销已获积分。日期和周一零点均按北京时间，累计积分保留，周榜仅汇总本周。

`progress-store.ts` 在每次档案或奖励写入前重读最新存储，档案按 ID 合并，完成记录按“孩子＋北京时间日期＋游戏”去重。一般交错写入可通过 `storage` 事件合并修复；各标签页保留自己当前选中的孩子，避免另一页切档案把本页奖励记错人。这依然是浏览器本地存储，不提供数据库事务、跨设备同步或严格并发保证；极端同时写入需要仍存活的标签页处理事件完成修复。

本页选中孩子同时固定到独立的 `sessionStorage` 键 `kexiaobei.science-games.v1.active-profile`，导航或硬刷新后优先恢复该页仍然存在的孩子；全局 `activeProfileId` 只作为没有本页记录时的默认值。清空／默认重置或重新载入时发现孩子已不存在，则回到合法默认档案并更新本页记录。sessionStorage 被禁用时降级到共享默认和内存，不阻止游玩；此时硬刷新后的标签页独立选择无法保证。

档案 ID 优先使用 `crypto.randomUUID`，局域网 HTTP 不具备该 API 时改用 `getRandomValues`，再后备为时间、随机量与递增序号组合，并检查已有 ID。ID 保存后保持不变，不因刷新重建。存储访问或写入失败时仍可在内存游玩，`storageError` 提醒无法可靠保存；存储恢复后，下一次操作会合并尚未保存的记录。

另一标签页删除该键、调用 `clear()` 或写回默认空档案视为明确重置：本页清空内存记录，不自动把旧记录写回。存储读取发现已删除或默认重置时也遵守这一语义。本机手册和本机探索榜仍可被浏览器清除或修改，不作为正式园方排名；联网榜读取账号手册中的服务端记录。

登录账号可主动开启账号手册；孩子档案和积分由服务端按账号隔离，游客仍可使用本机手册。离线完成事件保存在本机队列中，联网后可重试；联网榜通过公开字段接口读取。正式数据库迁移、预发布和跨设备真账号流程仍待验收，详见 [ROLLOUT.md](ROLLOUT.md) 与 [QA.md](QA.md)。

## 美术与开源

首页插画、头像、实验台、道具、水槽和光线以项目制作的 SVG、Canvas 与 CSS 绘制，无需生成图片即可运行。旧美术清单仍保留在 `src/lib/science-games/artwork.json`，素材目录为 `public/assets/science-games/`。清单里的文件状态不代表所有 Canvas 道具已自动换成贴图；后续接图需核对物体锚点、碰撞尺寸与渲染方式。

透明素材使用 PNG 真透明，不画白底或棋盘格。标题、按钮、分数、进度和动态反馈由网页绘制。旧需求包的问答构图不代表现版界面。

Matter.js 及磁力 Basic 示例的准确来源和完整 MIT 保留要求见 [OPEN_SOURCE.md](OPEN_SOURCE.md)；影子点光源计算和 SVG 美术为本项目制作。本模块适配开源物理示例，没有搬运一款完整现成游戏。

```powershell
npx vitest run src/lib/science-games

```

此前界面与玩法回归记录为 5 个文件、36 项测试通过，并完成生产构建与桌面模拟手机触控检查。本轮账号服务端和离线同步检查为 8 个文件、72 项测试通过；相关 ESLint 与全仓 TypeScript 检查通过。本地周榜接口连续 5 次返回 200，但曾观察到一次本地 503，正式数据库迁移、部署构建和真实手机／微信验收仍未完成，详见 [QA.md](QA.md)。
