# AI 平台与开发过程说明

## （一）平台/技术选择

本项目采用 Coze 智能体的设计思路，构建“龙湾区国科温州第二幼儿园园所信息智能体”。智能体面向家长、访客和教师，承担园所概览、科学资源、功能室、荣誉资质和实验活动等内容的中文问答任务。

平台由以下技术组成：

- **Coze 智能体工作流**：用于定义智能体角色、回答边界、知识优先级和对话流程。智能体先检索资料库，再结合上下文生成回答，避免脱离园所材料自由编造。
- **大模型服务**：负责理解自然语言问题、整合检索片段和生成简洁的中文回答。模型调用封装在服务端智能体工作流中，可按部署环境灵活配置，不影响上层知识检索与交互逻辑。
- **Next.js + TypeScript**：用于实现官网页面、实验室资源中心、对话界面和服务端接口，前后端在同一项目中部署。
- **Prisma + PostgreSQL**：存储园所资料、知识分块、科学资源、照片、功能室及用户数据。
- **Vercel**：用于持续部署网站和服务端接口；模型密钥仅配置在服务端环境变量中。

## （二）开发过程

### 1. 明确智能体角色与回答范围

在 Coze 智能体中设置角色为“龙湾区国科温州第二幼儿园园所信息问答助手”。回答范围限定为园所公开资料和科小贝科学资源，并明确以下规则：

- 优先依据资料库内容回答；
- 资料库没有明确依据时，回答“资料库暂未收录明确内容”；
- 回答面向家长、访客和教师，保持简洁、温和、可信；
- 涉及功能室、空间、环境和参观时，提示用户查看相关图片；
- 不向普通用户输出云宝设备状态、实时监控、日志和控制细节。

可复用的核心提示词如下：

```text
你是“龙湾区国科温州第二幼儿园”的园所信息问答智能体。
请优先依据已检索到的园所资料和科小贝科学资源回答。
若资料库没有明确依据，不要编造，并说明“资料库暂未收录明确内容”。
回答要适合家长、访客和教师阅读，简洁、温和、可信。
当问题涉及功能室、空间、环境、照片、图片或参观时，提醒用户查看下方相关图片。
不向普通用户提供云宝设备状态、实时监控、日志或控制细节。
```

### 2. 构建知识库

先将园所概况、办园资料、省二级评估自评报告、功能室资料、科学诗、科学故事和科学实验等材料整理为文本。系统将每份资料拆分为适合检索的知识片段，并保留资料标题、正文、图片、视频和二维码等关联信息。

用户提问后，系统先根据中文关键词、同义词和 n-gram 匹配检索相关片段；再将命中的片段、资料来源和最近 12 条消息（约 6 轮对话）作为上下文交给大模型。问候、感谢等纯闲聊会跳过资料检索，但仍保留对话上下文。这样既能回答连续问题，也能保证资料型回答可追溯到具体资料。

### 3. 设计交互逻辑

智能体对话采用“提问 - 检索 - 生成 - 展示来源 - 继续追问”的流程：

1. 用户在网页右下角的智能体对话框输入问题。
2. 服务端检索园所资料库和科学资源库，整理相关内容。
3. 将问题、检索上下文和最近对话发送到智能体工作流，由底层大模型生成中文回复。
4. 页面同时展示命中的资料来源；当用户询问功能室或环境时展示相关照片。
5. 当命中科学诗、科学故事或科学实验时，显示“查看《资料名称》”入口；用户点击后直接打开实验室的对应详情弹窗。
6. 模型服务未配置、超时或暂时不可用时，系统自动使用资料库检索结果生成回退回答，保证基础问答不中断。

### 4. 编写代码与接口

前端使用 React 组件实现悬浮对话窗口、消息列表、来源卡片、图片卡片和实验详情跳转。服务端通过 `POST /api/ai-chat` 接收用户问题，依次完成知识检索、上下文拼接、模型调用和结构化响应。

接口返回 `reply`、`sources`、`photos` 和 `labLinks` 四类数据：

- `reply`：智能体生成的中文回答或资料库回退回答；
- `sources`：回答依据的资料标题；
- `photos`：与功能室或环境问题相关的图片；
- `labLinks`：可直达实验室详情弹窗的科学资源链接。

这种结构使模型输出与页面交互解耦：即使更换底层大模型，资料来源、图片和实验详情跳转仍由系统控制，功能可稳定复用。

### 5. 形成可复用技能

项目将“园所资料问答”沉淀为可复用的智能体技能，包含：角色提示词、资料检索规则、上下文拼接规则、回答限制、来源展示和异常回退六部分。迁移到其他园所时，只需替换资料库内容、园所名称和少量提示词，即可复用同一套对话流程。

复现步骤如下：

1. 在数据库中导入园所资料和科学资源，并为资料生成知识检索分块。
2. 配置服务端数据库连接和大模型密钥。
3. 复制本说明中的角色提示词，配置 Coze 智能体工作流或等价的服务端提示词流程。
4. 启动项目后访问网页，在智能体对话框中输入园所、科学实验或功能室相关问题。
5. 检查回答是否包含资料来源、图片或实验详情入口；断开模型服务后，确认资料库回退回答仍可用。

通过以上流程，项目实现了“智能体对话 + 园所知识库 + 科学资源直达”的完整闭环，并能够在不同园所资料场景中复现。
