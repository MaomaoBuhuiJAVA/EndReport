# 短信账号功能实施计划

用户授权：在现有网页新增短信登录等对应卡片和功能，审核后可直接接入。沿用已有登录页样式，不发送真实短信、不更改生产数据库。

**Goal:** 提供短信登录、注册手机验证、找回密码和修改绑定手机号的完整页面与服务端接口。

**Architecture:** 阿里云 SendSms 服务端签名调用；默认关闭，通过公共只读状态显示开通情况。验证码绑定手机号、用途与账号，摘要保存于既有 PostgreSQL，并由事务保证单次使用与发送频率限制。短信开通前保留现有密码登录与注册。密码重置/手机号变更更新会话版本。

**Tech Stack:** Next.js / React / Prisma / PostgreSQL / Node crypto；复用现有依赖。

模板依据用户截图：登录 SMS_51215901；注册 SMS_512585836；修改/重置密码 SMS_512685888；修改绑定手机 SMS_512520955。签名与模板参数通过服务端环境变量配置。
