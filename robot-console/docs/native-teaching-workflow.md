# 国科二幼原生教学工作流

网站的科小贝通过自有工作流处理教学请求，文字、识图、图片生成和语音均直接调用千问 API，并复用现有语音密钥。上传素材、生成封面和作品保存到现有 OSS；资料关系继续存储在服务器 PostgreSQL。

迁移依据是用户提供的 `国科二幼教学智能体.yml`（51 个节点、9 类任务），其提示词与结构定义保存在 `src/data/teaching-workflow.json`。没有执行导出文件中的代码或导入其服务密钥。

| 教学需求 | 处理与交付 |
| --- | --- |
| 教案生成 | 根据年龄、主题、时长和实际园本资料生成完整文稿，可连续修改 |
| 资源检索 | 按标题、年龄、学期、类别和主题筛选；明确主题优先；步骤图、二维码、视频均来自当前条目；需要带读时基于真实诗文补充建议 |
| 文档解析与诊断 | 读取真实上传正文或公开文档链接；摘要、改写和家长回顾直接交付文稿；明确要求诊断或检查时返回诊断、证据缺口与修订稿 |
| 文档与课件 | 生成真实 DOCX、PDF、PPTX、XLSX；下载后可用原解析器再次读取 |
| 教学配图 | 直接调用通义图像服务，返回实际生成的图片 |
| 图片观察 | 先用视觉模型读取图片，区分可见事实和待验证判断 |
| 科学诗封面 | 根据上传诗文生成封面，支持 3:4、1:1、16:9；更改比例时保留诗文 |
| 实验复盘 | 返回事实、推测、问题、改进和下一次验证点，支持后续文件导出 |
| 作品反馈 | 返回鼓励、观察、问题和探究任务；推荐条目仅限本轮真实检索命中 |

普通问答和电话模式另有直接路径。问候本地返回；电话使用简短流式回复，在首个完整句子到达时开始合成音频，后续音频按顺序播放。挂断、静音、关闭播报会释放相应队列与播放等待。浏览器麦克风、播放权限和识别服务仍须在实际设备验收。

园所简介和功能室检索使用现有园所资料与对应房间照片；不使用科学诗/实验目录替代园所资料。未知房间返回未命中，内部人员名册和设备状态不进入普通教学回答。普通媒体查询直接交付真实资源；明确请求科学诗带读方法时才追加一次文本生成。

## 本地使用

从项目目录执行：

```powershell
npm install
npm run prisma:generate
$env:SEED_SCIENCE_ON_BUILD = '0'
$env:SEED_QUALIFICATION_ON_BUILD = '0'
npm run build
npm run start -- -p 3100 -H 127.0.0.1
```

依照 `.env.example` 使用已有服务端配置。旧的工作流开关不再参与路由，所有入口固定使用原生流程。模型密钥和 OSS AccessKey 均留在服务端。

| 配置 | 默认与用途 |
| --- | --- |
| `QWEN_TTS_API_KEY` | 共用现有千问语音密钥；未设置时使用 `DASHSCOPE_API_KEY`，再兼容 `QWEN_API_KEY` |
| `QWEN_API_BASE_URL` | 默认用户提供的 `https://maas.qianwenaiapi.com/api/v1`；文字/识图使用同一主机的 `/compatible-mode/v1/chat/completions` |
| `QWEN_TEXT_MODEL / QWEN_VOICE_MODEL` | 普通问答默认 `qwen3.5-plus` 并启用思考模式；电话默认 `qwen-flash`、关闭思考以保持低延迟 |
| `QWEN_VISION_MODEL` | 默认 `qwen3-vl-flash`；上传图片直接传给视觉 API，文档先提取实际正文 |
| `QWEN_IMAGE_MODEL` | 默认示例支持的 `qwen-image`，通过 multimodal-generation API 返回真实图片，每次一张，关闭水印 |
| `QWEN_TTS_MODEL / QWEN_TTS_VOICE` | 默认 `qwen3-tts-flash`、`Mochi`，复用同一密钥合成首句及后续音频 |
| `ALIBABA_CLOUD_ACCESS_KEY_ID / SECRET` | 复用现有 OSS 凭据；`ALIBABA_CLOUD_SECURITY_TOKEN` 仅在使用临时 STS 凭据时需要 |
| `OSS_BUCKET / REGION` | 当前 `guokemeitiku`、`oss-cn-hangzhou`；私有对象通过本站 `/api/media/…` 按资料公开状态及作品权限交付 |
| `AI_ARTIFACT_DIR / SECRET` | 私有持久文件目录及独立签名密钥；部署时须持久挂载，多实例须共享目录和密钥 |

附件格式、中文字体、输出分页、容量及有效期见 [文档与附件说明](native-teaching-documents.md)。生成文件和签名秘密放在 `.ai-artifacts`，已排除版本管理。当前文件交付使用私有磁盘，不具备无持久卷 Serverless 上的重启持久性。

## 接口与连续追问

`POST /api/ai-chat` 沿用现有 JSON / multipart 请求与 JSON / SSE 响应，新增 `provider: "native"` 和经过校验的 `workflowState`。客户端将最近一次成功响应的状态带入后续请求，包括当前任务、查询条件、文稿、附件证据和资源 ID。取消的请求不会更新状态。状态由客户端持有，服务端限制长度并将其视为用户数据。

“它的全部步骤图”“换成小班”“改为15分钟”“把刚才复盘导出Word”会延续相应任务；显式指定新实验标题会替换旧标题。纯格式转换复用已完成文稿，有内容修改的请求重新生成。后续上下文由经过校验的 `workflowState` 和最近对话承接。

完整教案导出 Word 时使用园所教育教学活动设计表，保留活动目标、准备、过程、重点难点与反思。聊天分隔符不再强制分页；活动过程按段落组续页，阶段标题与首段保持同页，续页重复两行基本信息。主题、班级和时长取连续对话中最后确认的条件。家长通知、活动回顾及原文提取继续使用普通文档格式。

“换成风的科学诗”会替换旧主题并保留年龄、学期等过滤；只换成科学实验或科学故事时保留原主题。未指定导出格式时只追问 Word/DOCX、PDF、PPTX 或 XLSX；状态区分复用已完成文稿和待生成的新需求，保留已经读取的附件与视觉证据。

JSON/multipart 可传入 `documentUrl`，也可在“提取、读取、概括文档正文”等自然请求中直接给出公开 HTTP(S) 链接。服务端实际读取页面或文件；正文提取保留页面标题，失败时返回可重试错误。纯文档摘要与家长回顾默认使用已读文档，不附带无关资料库来源；明确要求参照资料库或园本资料时才补充检索。

明确提取正文时直接展示已读取的全部文字，避免模型转述漏掉标题或段落；纯提取无需模型。有概括要求时只生成补充概括，原文由程序保留，并一起写入后续文稿和导出文件。

`GET /api/ai-chat/artifact?token=…` 下载签名对应的真实字节。无效、过期或被容量清理的文件返回 404。普通聊天配图使用千问返回的真实图片链接。资料库封面须成功保存到私有 OSS 并写入所选资料后才标记为已保存；存储或写回失败时仅展示本次临时结果，不把临时地址保存为长期封面。

## 素材与作品存储

`POST /api/science-resources/upload` 接受网站 FormData，资料文件上限 100MiB；小型内联上传保留 5MiB 上限。浏览器显示传输进度，服务端将字节写入私有 OSS 并返回本站稳定路径。科学诗识别独立保留 20MiB 上限，聊天附件仍为 4MiB。

作品上传保留 20MiB 上限及已核验教师/家长或管理员投稿权限，新作品为待审核、内部可见。未知上传对象没有公开权限；公开资料、审核通过的公开作品，以及作品作者/管理员各按原有规则读取。已迁移素材始终使用现有 OSS 对照表，无需旧的启用开关。

批量视频上传工具改用 OSS；批量故事封面通过千问 API 绘制。生成视频二维码时通过 `SITE_URL` 将站内媒体路径转成完整网站地址。历史媒体清单中的原始地址和对象键仅用于已迁移文件的对应关系。

批量上传先修改本地素材目录，OSS 文件此时仍为私有。工具会输出本次资料 ID 和实际目录绝对路径的 `syncCommand`：先执行 `npm run sync:science-media -- --item=资料ID --catalog=实际目录路径` 查看定向登记计划，确认目标 PostgreSQL 后添加 `--apply`。显式目录优先于环境变量，预览不创建数据库客户端。此步骤仅登记选定资料的媒体地址和实际图片数量，保留数据库正文、标题、用户投稿和已有私有权限；缺少资料或资源归属不一致时整笔拒绝。不要使用全量 `seed:science` 代替此步骤，后者会重建目录数据。日常网页上传和生成封面会由服务器完成登记。

旧 `/api/science-resources/sync-cover` 已停用；生成封面仅在服务器确认 OSS 保存成功后回写受控站内地址。学生作品始终先检查作品记录的审核与可见性，不能通过公开素材引用开放待审核作品。
