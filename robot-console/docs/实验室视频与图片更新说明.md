# 实验室视频与图片更新说明

更新日期：2026-07-30

## 本次功能修改

1. 恢复实验详情页的视频资料
   - 为 21 个科学实验补回了资料库中已有的视频跳转链接。
   - 详情弹窗新增“播放视频”按钮，点击后会在新页面打开对应视频。

2. 恢复视频二维码
   - 为每个实验视频生成了一个二维码，共 21 张。
   - 二维码和“播放视频”按钮来自同一个视频地址，手机扫码后会打开相同的视频。
   - 二维码文件保存在 `public/science-assets/video-qr/`，会随 Vercel 部署发布。

3. 调整详情弹窗展示
   - 视频按钮与二维码在同一资源区域展示。
   - 小屏幕会改为纵向排列，避免按钮和二维码互相挤压。

4. 保留并验证实验步骤图片
   - 实验步骤图片仍按原始文件的数字顺序展示。
   - 二维码不会混入实验步骤图片序列。

`E:\国科二幼\国科二幼智能体知识库\各学期\视频资源\README.md`

二维码原始图片也保留在实验素材文件夹中；网站发布的二维码由上述跳转链接重新生成，确保扫码地址和网页按钮一致。

## 后续更新方法

当视频链接有新增或修改时：

1. 更新对应学期的 `视频资源/README.md` 中的视频链接。
2. 在 `robot-console` 目录执行：

```powershell
npm run attach:science-videos
```

3. 执行测试：

```powershell
npm run test:science
```

4. 同步生产资料库并部署：

```powershell
npm run seed:science
npx vercel --prod
```
