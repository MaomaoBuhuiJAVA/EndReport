   - 图片标题使用“材料准备 N / 操作步骤 N”，封面优先取材料准备图片。
   - `自制泡泡液` 中 4 张完全相同的透明过渡图（原文件操作 18、23、25、26）保留源路径但不进入网页展示，操作步骤会重新连续编号。

## 后续更新方法

当视频链接有新增或修改时：

1. 更新对应学期的 `视频资源/README.md` 中的视频链接。
2. 在 `robot-console` 目录执行：

```powershell
npm run attach:science-videos
```

3. 执行测试：

```powershell
npm run test:science
```

4. 同步生产资料库并部署：

```powershell
npm run seed:science
npx vercel --prod
```
